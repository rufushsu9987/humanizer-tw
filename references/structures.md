# Structure and tone

## Formula essay

開頭總結 + 首先/其次/最後 + 金句 → 一句結論，接原稿裡就有的證據，再講風險。

## False parallelism

不僅是 A，更是 B → 直接說 B。

## Empty contrast

機遇與挑戰並存 → 說真正的 trade-off（錢 vs 延遲、人手 vs 隔離）。

## Review

建議依照最佳實務優化 → 哪個檔、會怎麼壞。

## Tone shifts

太硬 → 日常：

- 該服務應予以重構 → 這個 service 重寫比較快
- 敬談各位同仁驗收 → 請各位幫看一下
- 尚未進行完整驗證 → 還沒驗完
- 我認為我們需要進行討論 → 這件要再對一下

太豬 → 日常：

- 這塊直接爆掉重來吧 → 這塊不要了，重寫比較快
- 真的超讚這波 → 這次改過有用
- 大家趕緊 star 一下啦 → 需要的話可以 star
