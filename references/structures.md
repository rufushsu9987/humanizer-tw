# Structure problems

## Formula essay

Pattern: thesis sentence + 首先/其次/最後 + 金句.

Fix: one claim, then evidence already present, then risk.

## False parallelism

Pattern: 不僅是 A，更是 B. Repeated twice.

Fix: state B. If A matters, one clause.

## Empty contrast

Pattern: 雙刃劍 / 機遇與挑戰並存 / 在機遇中積極應對挑戰.

Fix: name the actual trade-off (cost vs latency, ops burden vs isolation).

## Fake completeness

Pattern: 全方位、多維度、系統性解決方案.

Fix: list the two or three things the system actually does.

## Review anti-pattern

Pattern: 建議依照最佳實務進一步優化.

Fix: file, line-level behavior, what breaks in prod.
